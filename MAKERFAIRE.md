

# The Mood Cam Project

Demonstrating lighting and IoT devices responding to a person's mood, based on face recognition.

#### Github Repo: 
https://github.com/accelerateorlando/iotai

## Technologies Involved

### Home Assistant
Home assistant is a vibrant open source community and platform for managing your Smart Home.  It is easy to get started and is super powerful.

https://www.home-assistant.io/

### Raspberry Pi
Raspberry Pi is a great hardward platform for IoT, it also can run AI Inference on the edge.

https://www.raspberrypi.com/

### Deep Face
Deep Face is an Open Source Python Library for Facial Recognition, Including Mood Detection!

https://github.com/serengil/deepface

### OpenCV
OpenCV is a Python Library for Computer vision, in this demo we use it for WebCam integration.

https://opencv.org/

### MQTT
MQTT (Message Queuing Telemetry Transport) is the standard for IoT messaging.  When the Python face recognition application detects a mood, it messages Home Assistant the update.

https://mqtt.org/

### Docker
Docker is used by Home Assistant for easily installing add ons, we use it to host our Python facial recognition application on the Raspberry Pi.

https://www.docker.com/

### Python
Python is the programming language of choice for AI Software Development, this entire application is only 300 lines of code thanks to the amazing libraries mentioned above.

https://www.python.org/

### AI Development Tools
OpenAI was used to generate an initial prototype, and enhancements and debugging was done in the Cursor IDE. 

https://openai.com/
https://cursor.com/
