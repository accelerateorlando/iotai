# Nano Banana Photo Booth

A photo booth using Google's Flash Image 2.5, code named [Nano Banana](https://aistudio.google.com/models/gemini-2-5-flash-image).
The model is hosted by [FAL](https://fal.ai/).

You can find the code for the application here: [https://github.com/accelerateorlando/iotai/tree/main/makerfaire-photobooth](https://github.com/accelerateorlando/iotai/tree/main/makerfaire-photobooth).

It was made in Python using Kivy, a cross platform UI library that is very touch screen friendly.  It was mostly [vibe coded](https://en.wikipedia.org/wiki/Vibe_coding) using [Cursor](https://cursor.com/).
